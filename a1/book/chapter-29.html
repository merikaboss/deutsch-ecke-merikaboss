Perfekt, Teil 3 — Partizip II

Irregular past participles, and how prefixed verbs behave

Original topic sheet View "Partizip II" in the Picture Book →

Chapter 28 covered the regular ge- + -t pattern. A core set of very common German verbs are "strong" instead — their stem changes in a way you simply can't predict, so they get memorized as vocabulary, not derived by rule.

📐 The irregular participles worth memorizing first

InfinitiveMeaningPartizip II
gehento gogegangen
kommento comegekommen
sehento seegesehen
essento eatgegessen
nehmento takegenommen
gebento givegegeben
fahrento drive/gogefahren
schreibento writegeschrieben
lesento readgelesen
wissento knowgewusst
seinto begewesen
habento havegehabt

There's no shortcut for this list — it's learned the same way irregular English past tenses are ("go/went/gone," not "go/goed/goed"). The good news: these are also the most-used verbs in the language, so repetition happens naturally.

How separable and non-separable verbs handle it

Both follow the regular -t pattern (or the irregular stem, if the base verb is irregular) — the only question is where ge- goes, or whether it appears at all.

TypeRuleExample
Separable (Ch. 21)ge- goes between the prefix and the stemaufstehen → aufgestanden
Non-separable (Ch. 26)no ge- at allverstehen → verstanden
-ieren verbsno ge-, just add -tstudieren → studiert

💬 Examples in full sentences

  • Wir sind früh aufgestanden. (We got up early.)
  • Ich habe das Problem verstanden. (I understood the problem.)
  • Sie hat in Berlin studiert. (She studied in Berlin.)

⚠️ Common mistake: forgetting the Partizip II entirely

"Ich habe gehen" is a genuinely common slip — using the plain infinitive instead of the participle. It has to be Ich bin gegangen (and note: with sein, not haben — gehen is a movement verb, per Chapter 28's rule).

Übungen (Exercises)

✏️ Try it yourself

1. Bilden Sie das Partizip II: sehen, essen, nehmen, schreiben.
2. Wählen Sie die richtige Form: Ich habe das Buch (gelesen / gelest). Sie ist nach Hause (gegehen / gegangen).
3. Bilden Sie das Partizip II von aufstehen und verstehen — erklären Sie den Unterschied. (Form both participles and explain the difference in how "ge-" behaves.)
4. Übersetzen Sie: "He has written a letter and given it to his mother." (Two irregular participles in one sentence.)
5. Fix the mistake: "Ich habe gehen zur Schule."
6. Write five sentences about last weekend, using five different irregular participles from the table above, correctly choosing haben or sein for each.
