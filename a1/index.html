How I'd use it

Two halves of the same topic

Each sheet in the Picture Book has a matching chapter in the Written Book, and they link to each other both ways.

1. Look at the sheet

Open the topic in the Picture Book and read it the way I first did.

2. Read the chapter

The written version explains the same material slowly, with every word translated.

3. Do the exercises

Each chapter ends with practice that gets harder as the book goes on.

4. Ask when stuck

The WhatsApp group is where we work out the things a book can't answer.
